## 1. 产品概述

### 1.1 一句话描述
仿真运维经理是一个业务上线发版前的准入管理系统，帮助运维经理通过标准化检查清单、自动化脚本验证和交付物管理，确保系统上线前满足所有运维准入要求。

### 1.2 目标用户
- **主要用户**：运维经理（责任方，负责准入审核）
- **次要用户**：
  - 系统管理员（提供台账数据、执行验证脚本）
  - 开发团队（提交交付物、配合整改）
  - 安全团队（审核安全相关要求）

### 1.3 核心价值主张
替代传统的纸质/Excel检查表和截图验证方式，通过结构化的检查清单、可执行的验证脚本、集中化的交付物管理，提升运维准入工作的效率、准确性和可追溯性。

## 2. 用户故事

### 2.1 核心场景

**场景 1 - 创建准入检查任务**
- 角色：运维经理
- 触发条件：新业务/系统准备上线
- 操作步骤：
  1. 创建新的准入检查任务，选择系统名称和上线时间
  2. 系统自动加载预设的检查模板（台账、基线、部署、安全、监控）
  3. 根据实际情况调整检查项和验收标准
  4. 分配检查任务给相关责任人
- 预期结果：生成结构化的准入检查任务，明确各项要求的责任人和验收标准

**场景 2 - 台账收集与审核**
- 角色：运维经理/系统管理员
- 触发条件：开始准入检查流程
- 操作步骤：
  1. 按模板要求填写应用系统台账（IP、主机名、配置等）
  2. 填写云服务开通台账（IAAS/PAAS层信息）
  3. 填写系统及软件账户台账（账户、权限、有效期等）
  4. 上传相关交付物（Excel/Word/PDF）
  5. 逐项确认并勾选完成
- 预期结果：完整的台账数据录入系统，交付物归档，状态更新为"已收集"

**场景 3 - 系统基线自动验证**
- 角色：运维经理
- 触发条件：进行基础资源标准化验证
- 操作步骤：
  1. 在目标服务器上执行预设的验证脚本
  2. 脚本自动检查：账户安全、磁盘分区、网络配置、基础环境
  3. 脚本返回结构化验证结果（通过/失败/警告）
  4. 失败的项显示详细信息和修复建议
- 预期结果：通过脚本验证替代人工截图检查，获得准确的基线合规状态

**场景 4 - 交付物上传与审核**
- 角色：开发团队/系统管理员
- 触发条件：完成某项要求的交付物
- 操作步骤：
  1. 在对应检查项下上传交付物（操作手册、脚本、日志、镜像包说明等）
  2. 系统自动识别文件类型并记录上传信息
  3. 运维经理在线预览或下载审核
  4. 审核通过后勾选确认
- 预期结果：所有交付物集中管理，可追溯，支持多种格式

**场景 5 - 准入检查进度跟踪**
- 角色：运维经理
- 触发条件：需要了解准入检查整体进度
- 操作步骤：
  1. 查看准入检查任务仪表盘
  2. 查看各维度（台账、基线、部署、安全、监控）完成进度
  3. 查看未完成的检查项和 blocker
  4. 导出检查报告
- 预期结果：实时掌握准入检查状态，及时发现和推动问题解决

## 3. 功能清单

### P0 - MVP 必需

| 功能模块 | 功能点 | 描述 | 验收标准 |
|---------|--------|------|---------|
| 准入任务管理 | 创建检查任务 | 创建新的准入检查，关联系统、版本、上线时间 | 任务创建成功，生成唯一ID，可配置检查范围 |
| 准入任务管理 | 检查模板管理 | 预设检查模板，支持自定义检查项 | 模板可配置，支持增删改检查项 |
| 准入任务管理 | 任务状态跟踪 | 查看任务整体进度和各维度完成情况 | 实时显示完成百分比，支持筛选和排序 |
| 台账管理 | 应用系统台账 | 录入IP、主机名、配置、用途、所属系统、责任人、上线时间 | 支持批量导入/导出Excel，字段完整性校验 |
| 台账管理 | 云服务开通台账 | 录入IAAS层（计算/网络/存储/备份）和PAAS/自部署软件版本 | 分类清晰，支持多实例录入 |
| 台账管理 | 系统账户台账 | 录入系统名称、服务器、IP、账户名、权限、持有人、有效期 | 账户有效期自动提醒，权限级别标准化选项 |
| 验证脚本管理 | 基线验证脚本 | 系统基线检查脚本（账户、磁盘、网络、环境） | 脚本在目标服务器可执行，返回结构化JSON结果 |
| 验证脚本管理 | 脚本执行记录 | 记录脚本执行时间、执行人、结果、输出日志 | 可追溯，支持查看历史执行记录 |
| 交付物管理 | 文件上传 | 支持Excel/Word/PDF/脚本文件上传 | 单文件最大50MB，支持在线预览 |
| 交付物管理 | 交付物关联 | 将交付物与具体检查项关联 | 一个检查项可关联多个交付物 |
| 交付物管理 | 交付物审核 | 运维经理审核交付物，确认/驳回 | 审核有备注，驳回需说明原因 |
| 检查项管理 | 检查清单展示 | 按管控维度分类展示检查项 | 支持展开/折叠，标记优先级 |
| 检查项管理 | 检查项确认 | 勾选确认检查项已完成 | 有确认时间、确认人记录 |
| 仪表盘 | 进度总览 | 可视化展示整体进度 | 饼图/进度条展示各维度完成情况 |
| 仪表盘 | 待办提醒 | 显示临近截止日期未完成的检查项 | 按紧急程度排序 |

## 4. 非功能需求

### 4.1 性能
- 页面加载时间 < 2s
- 文件上传支持断点续传
- 脚本执行结果异步返回，页面不阻塞
- 支持并发执行多个验证脚本

### 4.2 安全
- 用户认证：基于企业SSO或本地账号密码
- 权限控制：RBAC模型，细粒度到检查项级别
- 数据传输：HTTPS加密
- 敏感数据：账户密码等敏感信息加密存储
- 文件安全：上传文件病毒扫描，禁止执行文件上传

### 4.3 兼容性
- 浏览器：Chrome 90+, Edge 90+, Firefox 88+
- 脚本执行：支持Bash 4.0+的Linux服务器
- 文件格式：支持.xlsx/.xls/.doc/.docx/.pdf/.txt/.sh/.py

### 4.4 可用性
- 支持离线填写台账，网络恢复后自动同步
- 检查项支持批量确认
- 台账支持Excel模板下载和批量导入
- 表单自动保存草稿

## 5. 术语表

| 术语 | 解释 |
|-----|------|
| 准入检查 | 业务系统上线前，运维部门对其进行的合规性检查 |
| 台账 | 记录系统资源、配置、账户等信息的表格 |
| 基线 | 系统/软件配置的最低安全/标准化要求 |
| 交付物 | 证明某项要求已完成的文档、脚本、日志等材料 |
| 验证脚本 | 在服务器上执行，自动检查基线合规性的脚本 |
| IAAS | 基础设施即服务（计算、网络、存储等） |
| PAAS | 平台即服务（中间件、数据库等） |
| 管控维度 | 准入检查的分类（台账、基线、部署、安全、监控） |
