## 1. 产品概述

### 1.1 产品定位

**仿真运维经理**是一个面向运维专家和运维管理者的**计划驱动型准入管理系统**。系统帮助运维管理者在接到上线计划、变更计划等工作需求时，通过标准化的流程管理，确保所有交付物符合准入要求。

### 1.2 核心业务流程

```

│                         仿真运维经理 - 核心业务流程                          │
└─────────────────────────────────────────────────────────────────────────────┘

│ 上线/变更计划   │──────────▶│ 2. 选择范围     │──────────▶│ 8. 触发核验     │

```

### 1.3 目标用户

| 用户角色 | 主要职责 | 使用场景 |
|---------|---------|---------|
| **运维管理者** | 计划制定、范围选择、工作流编排、核验审批 | 创建计划、选择台账范围、拆解工作项、查看核验结果 |
| **运维专家** | 定义标准模板、配置验证规则 | 维护预置模板、配置脚本和AI分析规则 |
| **各业务团队** | 按工作项要求准备交付物 | 接收工作项要求、准备并提交交付物 |

### 1.4 核心价值

1. **计划驱动**：以计划为核心，所有工作围绕计划展开
2. **台账联动**：计划与台账管理深度关联，自动识别新增/更新需求
3. **标准化拆解**：将复杂计划拆解为可执行的工作项清单
4. **多维度核验**：人工、脚本、AI三种核验方式
5. **全链路追踪**：从计划创建到核验完成的完整追溯

## 3. 详细业务流程

### 3.1 第一阶段：计划制定

#### 3.1.1 接收工作需求

**触发条件**：运维管理者收到来自平台负责人的上线计划申请（线下已审批通过）

**输入**：
- 上线/变更申请（线下审批通过）
- 涉及的应用系统清单
- 计划执行时间要求

#### 3.1.2 创建计划

**操作步骤**：
1. 进入计划管理模块
2. 点击"创建计划"
3. 填写计划基本信息：
   - 计划名称
   - 计划分类（见下方分类体系）
   - 优先级（P0-P3）
   - 执行时间
   - 计划说明
4. 上传审批材料：
   - 会议纪要
   - 审批邮件
   - 其他截图

**计划分类与范围选择对应关系**（更新后）：

| 计划分类 | 说明 | 范围选择调用接口 | 操作类型 | 自动生成工作项 |
|---------|------|-----------------|----------|---------------|
| **新系统上线** | 全新业务系统首次上线 | 台账管理-新增应用系统台账 | 创建新台账 | 补充应用系统台账 |
| **新功能发布** | 现有系统新增功能模块上线 | 台账管理-查询应用系统台账 | 查询+编辑台账 | 补充新增的功能模块 |
| **业务功能变更** | 业务逻辑调整、功能优化 | 台账管理-查询应用系统台账 | 查询+勾选台账 | 更新应用系统台账 |
| **数据库变更** | 数据库结构变更、数据迁移 | 台账管理-查询应用系统台账 | 查询+勾选台账 | 更新数据库相关台账 |

**输出**：计划创建成功，系统自动生成PlanID和数据标签

1. 在计划详情页点击"拆解工作项"
2. 系统已根据计划分类和范围选择自动创建第一个工作项
3. 继续选择拆解方式添加其他工作项：
   - **方式A：使用预置模板**
     - 选择系统预置的工作项模板（5大类）
     - 自动加载对应的子工作项
   - **方式B：自定义拆解**
     - 手动创建父工作项（大类）
     - 在父工作项下创建子工作项
4. 调整工作项顺序，形成完整工作流

### 3.2 第二阶段：验收标准制定

#### 3.2.1 为子工作项制定验收标准

**操作步骤**：
1. 选择需要制定验收标准的子工作项
2. 选择验收标准来源：
   - **预置模板**：从知识库选择标准模板
   - **文档导入**：导入MD/Word/Excel格式的基线要求
   - **手动输入**：自定义输入验收标准
3. 配置核验方式：
   - 人工核验
   - 脚本自动核验
   - AI智能分析
4. 定义交付物要求（格式、内容要求）

**验收标准组成**（以"补充应用系统台账"为例）：

| 要素 | 说明 | 示例 |
|-----|------|------|
| 检查项 | 具体的检查内容 | "应用系统名称已填写" |
| 核验方式 | 如何验证 | 人工核验 |
| 通过标准 | 怎样算通过 | 字段不为空且格式正确 |
| 交付物 | 需要提交的材料 | 应用系统台账表（Excel） |

### 3.3 第三阶段：交付物准备与收集

#### 3.3.1 各团队准备交付物

**执行方**：各业务团队（线下执行）

**工作内容**：
- 按照工作项要求准备交付物
- 确保交付物符合验收标准
- 在计划执行时间前完成准备

#### 3.3.2 上传交付物

**操作步骤**：
1. 进入计划详情页
2. 找到对应的工作项
3. 点击"上传交付物"
4. 选择文件并上传（支持PDF、Word、Excel、图片等格式）
5. 填写交付物说明

**交付物状态流转**：

```
待上传 → 已上传 → 核验中 → 已通过
                    ↓
                 不通过/待改进
                    ↓
                 重新上传
```

### 3.4 第四阶段：核验执行

#### 3.4.1 触发核验

**触发条件**：交付物上传完成后，系统自动或手动触发核验

#### 3.4.2 执行核验

根据配置的核验方式，执行相应的核验操作：

**方式一：人工核验**
- 运维管理者查看交付物
- 对照验收标准进行检查
- 人工判断是否通过

**方式二：脚本自动核验**
- 系统自动执行预设脚本
- 脚本在目标服务器上运行
- 自动比对结果，生成报告

**方式三：AI智能分析**
- 系统自动解析交付物内容（如PDF报告）
- AI提取关键信息（如"通过"/"不通过"结论）
- 自动生成分析结果

#### 3.4.3 记录核验结论

**核验结论类型**：

| 结论 | 说明 | 后续操作 |
|-----|------|---------|
| **通过** | 交付物符合验收标准 | 标记完成，进入下一工作项 |
| **不通过** | 交付物不符合要求 | 退回，要求重新准备 |
| **待改进** | 基本符合，但有优化空间 | 记录问题，允许通过但需后续改进 |

### 3.5 第五阶段：计划完成

#### 3.5.1 计划状态更新

当所有工作项的核验结论都已确定后：
- 系统自动计算计划整体进度
- 更新计划状态为"已完成"
- 生成计划执行报告

#### 3.5.2 归档与复盘

- 所有交付物归档保存
- 核验结果汇总生成报告
- 支持后续审计和复盘分析


| holder_name | VARCHAR(50) | 是 | 持有人 | "王五" |
| holder_department | VARCHAR(100) | 否 | 持有人部门 | "运维部" |
| valid_from | DATETIME | 是 | 有效期开始 | 2024-01-01 00:00:00 |
| valid_until | DATETIME | 是 | 有效期结束 | 2024-12-31 23:59:59 |
| password_change_cycle | INT | 否 | 密码修改周期(天) | 90 |
| last_password_change | DATETIME | 否 | 上次密码修改时间 | 2024-03-01 10:00:00 |
| status | ENUM | 是 | 状态：active/expired/locked | "active" |
| related_plan_ids | JSON | 否 | 关联的计划ID列表 | ["plan-001", "plan-002"] |
| created_at | DATETIME | 是 | 创建时间 | 2024-01-01 10:00:00 |
| updated_at | DATETIME | 是 | 更新时间 | 2024-03-22 10:00:00 |

**权限级别说明**：

| 权限级别 | 说明 | 典型场景 |
|---------|------|---------|
| admin | 管理员权限，拥有完全控制权 | 系统管理员账号 |
| read | 只读权限，可查看但不可修改 | 只读查询账号 |
| write | 读写权限，可查看和修改数据 | 应用操作账号 |
| execute | 执行权限，可运行程序或脚本 | 定时任务账号 |

**账号安全特性**：
- **到期提醒**：账户到期前7天/3天/1天自动提醒
- **密码周期**：支持设置密码修改周期，到期前提醒
- **审计日志**：记录账号创建、修改、密码变更等操作

### 5.2 计划分类与台账管理接口对照表

| 计划分类 | 台账管理接口 | 操作类型 | 范围选择说明 | 自动生成工作项 |
|---------|-------------|---------|-------------|---------------|
| 新系统上线 | 新增应用系统台账 | 创建新台账 | 填写应用系统基础信息，含功能模块和模块上线时间 | 补充应用系统台账 |
| 新功能发布 | 查询应用系统台账 | 查询+编辑 | 选择已有台账，编辑功能模块和模块上线时间 | 补充新增的功能模块 |
| 业务功能变更 | 查询应用系统台账 | 查询+勾选 | 从台账列表中勾选涉及的应用系统（可多选） | 更新应用系统台账 |
| 数据库变更 | 查询应用系统台账 | 查询+勾选 | 从台账列表中勾选涉及的应用系统（可多选） | 更新数据库相关台账 |

**说明**：
- **新系统上线**：调用"新增应用系统台账"接口创建新台账，需填写完整的应用系统信息
- **新功能发布**：调用"查询应用系统台账"接口，选择后允许编辑功能模块和模块上线时间
- **业务功能变更**：调用"查询应用系统台账"接口，仅允许勾选已有台账（可多选）
- **数据库变更**：调用"查询应用系统台账"接口，仅允许勾选已有台账（可多选），不勾选云服务台账
