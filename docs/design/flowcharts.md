## 1. 整体业务流程

┌─────────────────────────────────────────────────────────────────────────────┐
│                         仿真运维经理 - 整体业务流程                           │
└─────────────────────────────────────────────────────────────────────────────┘

                              ┌──────────────┐
                              │   开始       │
                              └──────┬───────┘
                                     │
                                     ▼
                         ┌───────────────────────┐
                         │ 1. 创建准入任务        │
                         │ (定义上线系统、时间等)  │
                         └───────────┬───────────┘
                                     │
                                     ▼
                         ┌───────────────────────┐
                         │ 2. 选择/创建工作流模板 │
                         │ (选择预置标准或自定义)  │
                         └───────────┬───────────┘
                                     │
                                     ▼
                         ┌───────────────────────┐
                         │ 3. 创建工作流实例      │
                         │ (关联准入任务)         │
                         └───────────┬───────────┘
                                     │
                                     ▼
                         ┌───────────────────────┐
                         │ 4. 执行工作项检查      │
                         │ (按顺序执行各检查项)    │
                         └───────────┬───────────┘
                                     │
                    ┌────────────────┼────────────────┐
                    │                │                │
                    ▼                ▼                ▼
           ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
           │ 脚本验证     │  │ AI自动分析   │  │ 人工核验     │
           │ (系统基线)   │  │ (安全报告)   │  │ (台账收集)   │
           └──────┬───────┘  └──────┬───────┘  └──────┬───────┘
                  │                │                │
                  └────────────────┼────────────────┘
                                   │
                                   ▼
                       ┌───────────────────────┐
                       │ 5. 生成检查结果        │
                       │ (通过/不通过/待改进)    │
                       └───────────┬───────────┘
                                   │
                                   ▼
                       ┌───────────────────────┐
                       │ 6. 人工复核确认        │
                       │ (可修正自动分析结果)    │
                       └───────────┬───────────┘
                                   │
                                   ▼
                       ┌───────────────────────┐
                       │ 7. 生成综合报告        │
                       │ (汇总所有检查结果)      │
                       └───────────┬───────────┘

                                   ▼
                       ┌───────────────────────┐
                       │ 8. 完成准入检查        │
                       │ (判定是否允许上线)      │

┌─────────────────────────────────────────────────────────────────────────────┐

                                    │
                                    ▼
                    ┌────────────────────────────────┐
                    │ 获取工作流实例信息              │
                    │ - 基本信息                     │
                    │ - 所有工作项实例               │
                    │ - 所有交付物                   │
                    │ - 所有分析结果                 │
                    └───────────────┬────────────────┘
                                    │
                                    ▼
                    ┌────────────────────────────────┐
                    │ 统计汇总信息                    │

                    │ │ 总体进度:                  │ │
                    │ │ - 总工作项数               │ │
                    │ │ - 已完成数                 │ │
                    │ │ - 进度百分比               │ │
                    │ ├────────────────────────────┤ │
                    │ │ 结果统计:                  │ │
                    │ │ - 通过数                   │ │
                    │ │ - 不通过数                 │ │

                                    │

                    ┌────────────────────────────────┐

                    │ │ - 类型                     │ │
                    │ │ - 结果                     │ │
                    │ │ - 结果来源                 │ │
                    │ │ - 交付物列表               │ │
                    │ │ - 分析摘要                 │ │
                    │ └────────────────────────────┘ │
                    └───────────────┬────────────────┘
                                    │
                                    ▼
                    ┌────────────────────────────────┐
                    │ 生成建议项                      │
                    │ (基于未完成/待改进项)           │

                    ┌────────────────────────────────┐
