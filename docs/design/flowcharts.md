### 2.2 范围选择流程

#### 计划分类与范围选择对应关系

| 计划分类 | 范围选择调用接口 | 操作类型 | 自动生成工作项 |
|---------|-----------------|----------|---------------|
| 新系统上线 | 新增应用系统台账 | 创建新台账 | 补充应用系统台账 |
| 新功能发布 | 查询应用系统台账 | 查询+编辑台账 | 补充新增的功能模块 |
| 业务功能变更 | 查询应用系统台账 | 查询+勾选台账 | 更新应用系统台账 |
| 数据库变更 | 查询应用系统台账 | 查询+勾选台账 | 更新数据库相关台账 |

## 4. 状态流转图

### 4.1 计划状态流转

```
+-----------------------------------------------------------------------------+
|                            计划状态流转                                       |
+-----------------------------------------------------------------------------+

                              +--------------+
                              |    草稿      |
                              |   (DRAFT)   |
                              +------+-------+
                                     | 提交
                                     v
                              +--------------+
                              |   待执行     |
                              |  (PENDING)  |
                              +------+-------+
                                     | 到达执行时间
                                     | 或手动启动
                                     v
                              +--------------+
                              |   执行中     |
                              |(IN_PROGRESS)|
                              +------+-------+
                                     | 全部工作项完成
                                     v
                              +--------------+
                              |   已完成     |
                              | (COMPLETED) |
                              +--------------+

其他状态转换：
- 草稿 -> 已取消（CANCELLED）
- 待执行/执行中 -> 已延期（DELAYED）
- 执行中 -> 已暂停（PAUSED）-> 执行中
```

```
  |通过|  |待改|  |不通| |通过|  |待改|  |不通| |通过|  |待改|  |不通|
  |    |  |进  |  |过  | |    |  |进  |  |过  | |    |  |进  |  |过  |
  +----+  +----+  +----+ +----+  +----+  +----+ +----+  +----+  +----+

结论说明：
+--------+--------------------------------------------------------+
|  通过  | 交付物完全符合验收标准，工作项完成                     |
+--------+--------------------------------------------------------+
| 待改进 | 基本符合但有优化空间，记录问题后允许通过，需后续改进   |
+--------+--------------------------------------------------------+
| 不通过 | 不符合验收标准，退回重新准备                           |
+--------+------------------------------+--------------------------+
```

## 5. PlanID与数据标签生成规则

### 5.1 PlanID生成规则

```
+-----------------------------------------------------------------------------+
|  PLAN-YYYYMMDD-XXX                                                          |
|  |    |        |                                                            |
|  |    |        └── 当日序号（001-999）                                      |
|  |    └─────────── 日期（如：20240323）                                     |
|  └──────────────── 固定前缀                                                  |
+-----------------------------------------------------------------------------+

示例：PLAN-20240323-001
```

### 5.2 数据标签生成规则

```
+-----------------------------------------------------------------------------+
|  [分类]-[范围]-[优先级]-[时间戳]                                            |
|                                                                             |
|  分类：                                                                     |
|    ONLINE-NEW    = 上线类-新系统上线                                       |
|    ONLINE-FUNC   = 上线类-新功能上线                                       |
|    CHANGE-BIZ    = 变更类-业务功能变更                                     |
|    CHANGE-DB     = 变更类-数据库变更                                       |
|                                                                             |
|  范围：                                                                     |
|    NEW           = 新增                                                    |
|    UPDATE        = 已有台账                                                |
|                                                                             |
|  优先级：P0/P1/P2/P3                                                        |
|                                                                             |
|  时间戳：Unix时间戳                                                         |
+-----------------------------------------------------------------------------+

示例：ONLINE-NEW-P1-1711171200
```
