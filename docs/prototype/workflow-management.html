配置验收标准
📊 服务对象台账收集 inventory
1.1 应用系统台账表 人工核验
确保所有应用系统信息完整可追溯
IP 主机名 配置(CPU/内存/磁盘) 用途 所属系统 责任人 上线时间
📎 交付物：应用系统台账表（Excel格式）
1.2 云服务开通台账表 人工核验
确保云服务资源清晰可控
IAAS层：计算服务(ECS/VM/容器)、网络服务(VPC/SLB/安全组)、存储服务(对象存储/块存储/NAS)、备份服务(快照/备份策略)
PAAS层：数据库(MySQL/Redis/MongoDB等)、消息队列(Kafka/RabbitMQ等)、缓存服务、其他中间件
📎 交付物：云服务开通台账表（Excel格式）
1.3 系统及软件账户台账表 人工核验
确保账户权限清晰、安全可控
系统名称 服务器名称 IP 系统账户名 软件账户名 权限级别 持有人 有效期 密码修改周期
📎 交付物：系统及软件账户台账表（Excel格式）
🏗️ 基础资源标准化交付 resource_delivery 预置标准
2.1 生产环境上线前系统基线配置 脚本验证
确保系统符合安全基线要求，通过验证脚本直接在服务器内执行，比截图更准确可靠
详细检查项（7项）
① 系统账户安全 - 设定符合《账户创建以及权限》基线要求
② 磁盘分区合规 - 系统盘与应用/数据盘物理或逻辑隔离
③ 网络安全 - 防火墙策略最小化，仅开放必要端口
④ 系统基础环境配置 - 时区同步(NTP)、字符集(UTF-8)
⑤ 自动更新控制 - 禁止机器自动重启、禁止自动更新
⑥ 证书管理 - 证书导入(如有)
⑦ 其他安全基线 - 符合组织安全基线要求
🤖 脚本自动化验证配置
✓ 系统基线检查脚本（SSH远程执行）
✓ 自动解析脚本输出结果（JSON格式）
✓ 生成脚本执行报告
📎 交付物：操作手册 / 云上镜像包 / 脚本执行报告
2.2 生产环境软件标准化部署 脚本验证
确保软件部署标准化、可复现
详细检查项（4项）
① 安装路径规范 - 符合《软件创建及目录权限》基线要求
② 安装脚本规范 - 符合bash4.0标准
③ 一键部署 - 支持一键式成功部署
④ 日志记录 - 保存成功安装的日志记录
🤖 脚本自动化验证配置
✓ 软件部署检查脚本（验证路径、权限、日志）
✓ 安装脚本语法检查（bash4.0标准）
📎 交付物：操作手册 / 安装脚本 / 安装日志
🛡️ 安全基线核验 security_baseline 预置标准
安全加固报告核验 AI自动分析
安全团队提供的加固报告显示"通过"，覆盖密码安全、漏洞情况、网络安全等
🧠 AI自动分析流程
  1. 上传安全扫描报告（PDF/Word格式）
  2. AI自动提取报告结论部分
  3. 判断是否标注"通过/不通过"
  4. 生成分析结果，人工复核确认
📎 交付物：安全扫描报告（PDF/Word格式，安全团队提供）
🔐 生产环境权限移交 permission_handover
权限移交确认 人工核验
确认生产环境访问权限已正确配置和移交
检查项
生产环境账户已创建
权限配置符合最小化原则
权限移交文档已签署
📎 交付物：权限清单 / 移交文档
📈 监控告警配置确认 monitoring
监控告警配置验证 脚本+人工
验证云监控Agent安装、监控指标接入、告警阈值和接收人配置
检查项（3项）
① 云监控(Cloud Monitor) Agent已安装
② 确认监控指标已接入统一监控平台（自建）
③ 确认告警阈值合理，告警接收人已配置
🤖 脚本验证
✓ Agent安装状态检查脚本
📎 交付物：监控配置截图 / Agent状态报告
