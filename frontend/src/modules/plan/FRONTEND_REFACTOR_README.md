# 创建计划流程前端改造说明

## 改造概述

本次改造对标后端台账管理集成功能，对前端"创建计划"流程进行了全面升级，实现了计划管理与台账管理的深度集成。

## 改造内容

### 1. 涉及范围步骤 (InventoryScopeStep.jsx)

#### 主要改动：
- **新系统上线场景**：新增创建应用系统台账功能
  - 添加"创建台账"按钮和表单弹窗
  - 支持填写应用名称、系统类型、部署环境、版本、负责人等信息
  - 创建成功后显示台账信息摘要

- **功能模块管理增强**：
  - 支持从已有应用系统选择模块（功能变更场景）
  - 添加模块选择弹窗，支持多选
  - 自动填充选中模块的当前版本信息

- **交互优化**：
  - 添加删除确认弹窗，防止误操作
  - 优化不同计划分类的界面展示逻辑

#### 新增状态：
```javascript
// 新系统创建相关状态
const [inventoryFormVisible, setInventoryFormVisible] = useState(false);

// 模块选择相关状态
const [selectedModules, setSelectedModules] = useState([]);

```

### 2. 预览确认步骤 (PreviewStep.jsx)

#### 主要改动：
- **新增数据同步预览卡片**：
  - 根据计划分类显示不同的同步操作预览
  - 使用时间轴展示同步步骤
  - 包含图标和状态标识

- **新增关联应用系统展示**：
  - 显示已选择的应用系统标签
  - 支持显示应用系统名称（从store中获取）

- **优化提交提示**：
  - 明确告知用户计划完成后将自动同步数据到台账管理系统

#### 同步预览信息：
| 计划分类 | 同步操作 |
|---------|---------|
| 新系统上线 | 创建应用系统台账 + 创建功能模块 + 生成生命周期日志 |
| 新功能上线 | 创建功能模块 + 生成功能上线日志 |
| 功能变更 | 更新功能模块 + 生成功能变更日志 |
| 架构变更 | 更新应用系统 + 生成架构变更日志 |
| 安全检查 | 仅生成安全检查日志 |

### 3. PlanStore 状态管理

#### 新增 Action：
```javascript
/**
 * 创建应用系统台账（新系统上线场景）
 */
createInventoryApplication: async (data) => {
  set({ loading: true });
  try {
    const result = await createInventory(data);
    // 刷新台账列表
    await get().fetchInventoryList();
    return result;
  } catch (error) {
    console.error('创建应用系统台账失败:', error);
    throw error;
  } finally {
    set({ loading: false });
  }
},
```

## 使用流程

### 新系统上线流程：
1. 填写基本信息（计划名称、分类等）
2. 上传审批材料
3. **创建应用系统台账** → 填写台账信息 → 创建成功
4. **添加功能模块** → 填写模块信息 → 保存
5. 预览确认，查看数据同步预览
6. 提交计划

### 功能变更流程：
1. 填写基本信息
2. 上传审批材料
3. **选择应用系统** → 从下拉列表选择
4. **选择已有模块** → 从弹窗选择需要变更的模块
5. 编辑模块变更信息（版本、说明等）
6. 预览确认
7. 提交计划

## 技术实现

### 组件依赖关系：
```
PlanCreateView
  └── PlanStepsForm
       ├── BasicInfoStep (未改动)
       ├── ApprovalFilesStep (未改动)
       ├── InventoryScopeStep (✅ 已改造)
       │    ├── 台账创建弹窗
       │    ├── 模块选择弹窗
       │    └── 模块编辑表单
       └── PreviewStep (✅ 已改造)
            └── 数据同步预览
```

### 数据流：
```
用户操作 → PlanStore Action → API 请求 → 后端处理 → 返回结果 → 更新 Store → UI 更新
```

## 注意事项

1. **台账创建时机**：仅在"新系统上线"分类时显示创建台账功能
2. **模块选择限制**：仅在"功能变更"分类时支持从已有系统选择模块
3. **数据同步说明**：预览步骤明确告知用户计划完成后的自动同步行为
4. **错误处理**：所有 API 调用都有错误提示，使用 Ant Design 的 message 组件
