## 2. 页面详情

### 2.1 登录页 (/login)

**功能描述**: 用户登录系统

**布局结构**:
```
+------------------+
|                  |
|   [Logo]         |
|   仿真运维经理    |
|                  |
|   用户名 [      ]|
|   密码   [      ]|
|                  |
|   [  登 录  ]    |
|                  |
+------------------+
```

**交互说明**:
| 元素 | 事件 | 响应 |
|-----|------|-----|
| 登录按钮 | click | 验证成功后跳转到仪表盘 |
| 用户名/密码 | enter | 触发登录 |

**状态变化**:
- 登录中: 按钮显示"登录中..."，禁用状态
- 登录失败: 显示错误提示"用户名或密码错误"

## 3. 组件规范

### 3.1 状态标签 (Badge)

| 状态 | 颜色 | 使用场景 |
|-----|------|---------|
| 草稿 | 灰色 | task_status: draft |
| 进行中 | 蓝色 | task_status: in_progress |
| 待审核 | 橙色 | task_status: pending_review |
| 已通过 | 绿色 | task_status: passed, checklist_item passed |
| 已驳回 | 红色 | task_status: rejected, checklist_item rejected |
| 不适用 | 灰色 | checklist_item: na |

### 3.2 按钮规范

| 类型 | 样式 | 使用场景 |
|-----|------|---------|
| Primary | 蓝色填充 | 主要操作：创建、保存、提交 |
| Secondary | 白色边框 | 次要操作：取消、返回 |
| Success | 绿色填充 | 成功操作：确认完成、通过 |
| Danger | 红色填充 | 危险操作：删除、驳回、取消任务 |
| Text | 文字链接 | 弱操作：查看、编辑、预览 |

### 3.3 表单规范

- **标签对齐**: 右对齐，宽度 120px
- **必填标记**: 红色星号 *
- **错误提示**: 字段下方红色文字提示
- **帮助文字**: 字段下方灰色小字说明

### 3.4 表格规范

- **表头**: 浅灰色背景，文字加粗
- **行高**: 48px
- **hover**: 浅灰色背景
- **操作列**: 图标按钮（查看👁、编辑✏️、删除🗑）
- **分页**: 底部居中，显示总数

## 4. 全局交互

### 4.1 导航
- **面包屑**: 顶部显示当前位置，可点击返回
- **侧边栏**: 可收起/展开，当前项高亮

### 4.2 反馈
- **成功**: Toast 提示，绿色，2秒自动消失
- **错误**: Toast 提示或内联错误，红色
- **警告**: Toast 提示，黄色
- **加载**: 骨架屏或 Loading 动画
- **确认**: Modal 弹窗，重要操作二次确认

### 4.3 响应式断点

| 断点 | 宽度 | 布局调整 |
|-----|------|---------|
| Desktop | >= 1200px | 完整布局 |
| Tablet | 768px - 1199px | 侧边栏收起 |
| Mobile | < 768px | 隐藏侧边栏，汉堡菜单 |

### 4.4 快捷键

| 快捷键 | 功能 |
|-------|------|
| Ctrl+S | 保存表单 |
| Esc | 关闭弹窗 |
| / | 聚焦搜索框 |
